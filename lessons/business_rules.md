# 业务规则沉淀

## 列名识别规则
- 业务主键ID：优先「业务主键ID」，其次「主键」，兜底「招标序号」
- 招标货品名：优先「销售货品名」，其次「货品名/物料名称/品名/名称」
- 供货货品名：优先「供货货品名」，其次「销售货品名/货品名/物料名称/品名/名称」
- 单位列：含「单位」
- 数量列：含「数量」，其次「采购数量/需求数量/供货数量/库存数量」
- 单价列（供货侧）：优先「实际供货单价」，其次「供货单价/单价/报价」

## 清洗规则
- 货品名：去首尾空格 → html.unescape 还原 HTML 实体 → 全角转半角(NFKC) → 去除末尾数字（如"pH传感器4" → "pH传感器"）
- 单位：去空格、统一小写、全角转半角
- 数量：转数值，整数统一为整数形式字符串（9.0 → "9"）
- html.unescape 作用：将 `&amp;` `&lt;` `&gt;` `&#xx;` 等 HTML 实体还原为原始字符（`&` `<` `>` 等）；对正常 `&` 字符无副作用
- 最终输出 goods_name 时也需对原始供货名称调用 html.unescape，确保不残留 HTML 实体形态

## 匹配规则
- 三键精确匹配：清洗后货品名 + 单位 + 数量
- 一对多时取供货清单第一条
- 金额 = 供货单价 × 数量，保留2位小数
- 未匹配项不返回

## 数据合法性原则
- 原始 Excel 数据永远正确，货品名中出现 `&`、`/`、`-`、中英文混排、数字、特殊符号均为合法业务数据，原样输出
- 匹配率低、未匹配项多属于业务正常结果，不得放宽规则或重跑
